In-progress skills are excluded from default discovery and installation. Their individual READMEs provide explicit install commands for testing them.

## Install

List the skills:

```bash
npx skills add gaelcado/skills --list
```

Choose available skills and install them globally:

```bash
npx skills add gaelcado/skills -g
```

Each skill README also provides an individual global-install command.
